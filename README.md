# RAM1212 CH6 Lab — Digital Marketing Research ด้วย Google Sheets

Interactive Lab ประกอบการสอนวิชา RAM1212 บทที่ 6 (Digital Marketing Research) คณะวิศวกรรมศาสตร์ มหาวิทยาลัยรามคำแหง ให้ผู้เรียนฝึกใช้สูตร Google Sheets (`SUM`, `AVERAGE`, `COUNTIF`, `IF`, `CHOOSE` ฯลฯ) ผ่านภารกิจจำลองการทำวิจัยตลาดร้านชานมหน้ามหาวิทยาลัย เป็นไฟล์ HTML/CSS/JS เดี่ยวจบต่อไฟล์ ไม่ต้อง build ไม่ต้องติดตั้ง ไม่ต้องเข้าสู่ระบบ เปิดผ่านเบราว์เซอร์ได้ทันที

**เข้าใช้งาน:** เปิด [`index.html`](index.html) เพื่อเลือกครั้งที่สอน หรือเปิดตรงที่ [`week1.html`](week1.html) / [`week2.html`](week2.html)

| `teacher-guide.html` | คู่มือสำหรับผู้สอน |

## การเข้าถึงบทเรียน (Access Gate)

ทุกหน้าจะขึ้นหน้า **"กรอกรหัสผ่านเพื่อเข้าสู่สนามแข่ง"** ก่อนเข้าเนื้อหา โดยรับรหัสได้สองรูปแบบ

1. **รหัสนักศึกษาตัวเลข 10 หลัก** (เช่น `69XXXXXXXX`) — ระบบจะจำรหัสนี้ไว้และเติมลงช่องรหัสนักศึกษาในแล็บให้อัตโนมัติ
2. **รหัสผ่านรวมของคลาส** — ผู้สอนเป็นผู้แจกให้ผู้เรียนในคาบ (ไม่ระบุไว้ในเอกสารนี้)

เมื่อผ่านแล้วระบบจะจำไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น จึงไม่ต้องกรอกซ้ำทุกหน้าและทุกครั้งที่กลับมาเล่น หากต้องการล้างสถานะให้รันคำสั่ง `localStorage.removeItem('ram1212_gate')` ใน Console

> **ข้อจำกัดที่ต้องทราบ:** การกั้นนี้ทำงานฝั่งไคลเอนต์ทั้งหมด ผู้ที่เปิดดูซอร์สโค้ดหรือ Console ย่อมทราบเงื่อนไขการปลดล็อกได้ จุดประสงค์คือความเป็นระเบียบของคลาสและการผูกผู้เล่นกับรหัสนักศึกษา **ไม่ใช่การยืนยันตัวตนเชิงความปลอดภัย** จึงไม่ควรนำไปใช้กั้นข้อมูลที่เป็นความลับ

## กลไกหลัก

- รูปแบบคำถามทุกจุดใช้ **"ทาย → ยืนยัน → เฉลย"** เพื่อให้ผู้เรียนคิดก่อนเห็นคำตอบ
- มี **Formula Engine** จำลองการทำงานของ Google Sheets ในตัว พร้อม MiniSheet UI ให้ฝึกพิมพ์สูตรจริง
- คะแนน/ตราสะสม (badge) บันทึกไว้ใน `localStorage` ของเบราว์เซอร์ผู้เล่นเอง lab จึงทำงานได้ครบทุกฟังก์ชันแบบออฟไลน์

## การเชื่อมต่อ Google Sheets (สำหรับผู้สอน)

โค้ดในไฟล์ `week1.html` / `week2.html` ที่เผยแพร่ในรีโปนี้ **ไม่ได้ฝัง URL ของ Google Apps Script Web App ไว้ในซอร์สโค้ด** โดยตั้งใจ (`CONFIG.sheetsWebAppUrl` ถูกปล่อยว่างไว้) เพื่อไม่ให้ endpoint จริงถูกเปิดเผยต่อสาธารณะในรีโปที่เป็น Public ซึ่งอาจถูกผู้ไม่ประสงค์ดียิง request เข้าไปป่วนข้อมูลในชีตได้

วิธีใช้งานจริงกับคลาสเรียน:

1. Deploy `ram1212-ch6-AppsScript.gs` เป็น Web App ของท่านเอง (ไม่ได้รวมอยู่ในรีโปนี้) แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
2. ต่อท้ายลิงก์หน้าเมนูด้วยพารามิเตอร์ `wa` เพียงครั้งเดียว โดยใช้ได้ทั้งสองรูปแบบ

   ```
   https://<your-domain>/index.html?wa=https://script.google.com/macros/s/XXXX/exec   ← วาง URL ดิบได้เลย
   https://<your-domain>/index.html#wa=<URL ที่เข้ารหัสด้วย encodeURIComponent>        ← ปลอดภัยกว่า
   ```

3. แจกลิงก์นี้ให้ผู้เรียนแทนลิงก์เปล่า ระบบจะตั้งค่า `CONFIG.sheetsWebAppUrl` ให้อัตโนมัติ **พร้อมจำไว้ใน `localStorage` ของเบราว์เซอร์นั้น** และส่งต่อค่าไปยังลิงก์ครั้งที่ 1 / ครั้งที่ 2 ในหน้าเมนูให้ด้วย จึงไม่ต้องต่อพารามิเตอร์ซ้ำในแต่ละหน้า

ระบบรับเฉพาะ URL ที่ขึ้นต้นด้วย `https://script.google.com/` เท่านั้น ค่าที่ชี้ไปโดเมนอื่นจะถูกปฏิเสธทิ้ง เพื่อกันการสร้างลิงก์ปลอมที่เปลี่ยนปลายทางการส่งข้อมูลของผู้เรียนไปยังเซิร์ฟเวอร์ของบุคคลที่สาม

**เปรียบเทียบสองรูปแบบ:** ค่าใน fragment (`#wa=`) เป็นข้อมูลฝั่งไคลเอนต์ล้วน ๆ เบราว์เซอร์ไม่ส่งไปกับคำขอ HTTP จึงไม่ปรากฏใน server log ไม่ติด `Referer` header และบอทพรีวิวลิงก์มองไม่เห็น ขณะที่ query string (`?wa=`) สะดวกกว่าเพราะวาง URL ดิบได้ทันที แต่ค่าจะถูกส่งไปถึงเซิร์ฟเวอร์ที่โฮสต์หน้าเว็บด้วย หากใช้แบบ `?wa=` แนะนำให้เปิดที่หน้าเมนูครั้งเดียว แล้วให้ระบบส่งต่อค่าแบบ `#wa=` ไปยังหน้าถัดไปเอง

**ทดสอบบนเครื่องของผู้สอนเอง** โดยไม่ต้องพ่วง fragment ทุกครั้ง: เปิด Console ของเบราว์เซอร์ (F12) แล้วรัน

```js
localStorage.setItem('sheetsWebAppUrl', 'https://script.google.com/macros/s/XXXX/exec')
```

ค่านี้จะอยู่เฉพาะในเบราว์เซอร์เครื่องนั้น ไม่ถูกเผยแพร่ไปกับซอร์สโค้ดหรือลิงก์ที่แชร์

## ข้อควรทราบเพิ่มเติม

ระบบสร้าง/ตรวจ "รหัสจบบทเรียน" ในหน้า `week2.html` เป็นการคำนวณฝั่งไคลเอนต์ทั้งหมด (ผู้ที่เปิดดูซอร์สโค้ดหรือ Console สามารถศึกษาอัลกอริทึมได้) จึงควรใช้เป็น **ตัวช่วยยืนยันเบื้องต้นหน้าห้องเท่านั้น** ไม่ใช่หลักฐานหลักในการให้คะแนน หลักฐานหลักที่แนะนำให้ใช้อ้างอิงคือบันทึกที่ถูกส่งเข้า Google Sheets ผ่าน Apps Script ซึ่งมีการประทับเวลา (timestamp) กำกับไว้ทุกรายการ
